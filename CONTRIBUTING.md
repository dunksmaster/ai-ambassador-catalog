# Contributing

Thanks for helping keep this list accurate.

## Add a program
1. Make sure it isn't already in `data/programs.yaml`.
2. It must be an **ambassador / champion / fellow / community-leader program** run by an AI lab, AI tool, or developer-tool company. No crypto/web3, and no programs that are only affiliate or referral links.
3. Add a row with every field from [schema.md](schema.md). Leave a field as `""` if the official page doesn't say. Don't guess perks or deadlines.
4. Use the official program or apply URL only. Never use a personal referral, tracking, or application-status link.
5. Set `last_checked` to the date you opened the page.
6. Mirror the row in the README table for its category.

## Update or close a program
- Bump `last_checked` whenever you re-verify a row.
- If a program is closed or paused, set `status: closed` and say so in your PR. Remove a row only if the program no longer exists.

## Don't include
Personal data of any kind: names, emails, application status, notes about your own applications.
