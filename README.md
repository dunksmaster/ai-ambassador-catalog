# Ambassador Catalog: AI & Dev-Tool Ambassador Programs

A curated, regularly re-checked list of **ambassador, champion, fellow and community-leader programs** run by AI labs, AI tools and developer-tool companies.

- **35 programs**, every link checked on the date shown.
- Only AI and dev-tool programs. No crypto/web3, no pure affiliate schemes.
- Perks, eligibility and deadlines come from each program's own page. If a field shows "—", we don't know it yet. We never guess.
- Canonical data lives in [`data/programs.yaml`](data/programs.yaml). The tables below mirror it.

> "Live" means the program page loaded and showed an apply path on the *Last checked* date. Intake windows change, so always confirm on the program page before applying.

## Contributing

Found a new program, a dead link, or a closed cohort? PRs are welcome.

1. Read [CONTRIBUTING.md](CONTRIBUTING.md) and [schema.md](schema.md).
2. Edit `data/programs.yaml` first, then mirror the row in this README.
3. Link only to the official program or apply page. No referral links.
4. Open a PR using the template.
